1. **修复正式版录制入口**：解决点击直接录制或带稿录制时出现的 `Untrusted prompter request` 报错，恢复稿件准备、提词浮窗和跳过准备的操作。

提供 Apple Silicon（arm64）和 Intel（x64）安装包，需要 macOS 14 或更新版本。

此版本需要手动安装和更新，尚未经过 Developer ID 签名和 Apple 公证。打开 DMG 后，将 Captor 拖入“应用程序”；首次打开被系统拦截后，在“系统设置 → 隐私与安全性”中选择“仍要打开”。

更新前请保存工作并退出 Captor。临时签名的构建替换后，原来的屏幕录制授权可能失效。若权限已开启却仍被拒绝，请完全退出 Captor，运行 `tccutil reset ScreenCapture dev.captor.app`，再从“应用程序”打开并重新授权，然后退出并重新打开。该命令只重置 Captor 的屏幕录制授权，工程与素材会保留。
