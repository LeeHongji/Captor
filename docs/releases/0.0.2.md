1. **淡紫与白色界面**：更新应用图标、浅色与深色主题，统一编辑器和浮窗的选中状态。
2. **更直接的操作反馈**：录制控制栏切换状态时立即响应，并支持系统的减少动态效果设置。
3. **口播准备与提词**：保存一份录制草稿，排练时使用浮窗和本地实时跟读，也可以跳过准备直接录制。
4. **macOS 安装与版本检查**：提供 Apple Silicon 和 Intel 安装包，在应用内检查新版本并前往下载。

需要 macOS 14 或更新版本。Apple Silicon 请下载 arm64，Intel 请下载 x64。

此版本需要手动安装和更新，尚未经过 Developer ID 签名和 Apple 公证。打开 DMG 后，将 Captor 拖入“应用程序”；首次打开被系统拦截后，在“系统设置 → 隐私与安全性”中选择“仍要打开”。受管理的电脑可能限制此操作。

更新前请保存工作并退出 Captor，再替换应用。录制、编辑和导出均在本地完成。
