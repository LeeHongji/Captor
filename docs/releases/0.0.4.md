1. **首次录制准备向导**：集中检查安装环境、屏幕与鼠标权限、麦克风和摄像头、本地语音模型，并通过五秒试录确认录制、保存与播放可用。
2. **权限修复入口**：权限已开启却仍被拒绝时，可在向导中检查当前状态、重启应用或确认重置对应授权，启动与返回系统设置时不再反复弹出权限提示。
3. **设备测试与选择**：麦克风音量、摄像头预览和语音跟读可在录制前测试，也可以明确关闭暂时不用的功能，继续使用直接录制和手动提词。

4. **完整的录制音频**：录制结束后将系统声音与麦克风声音合入 MP4，保留独立轨道供编辑；修复混合音频格式漏声、麦克风起始时间偏移和旧版仅麦克风录制重复播放的问题。

提供 Apple Silicon（arm64）和 Intel（x64）安装包，需要 macOS 14 或更新版本。

此版本需要手动安装和更新，尚未经过 Developer ID 签名和 Apple 公证。打开 DMG 后，将 Captor 拖入“应用程序”；首次打开被系统拦截后，在“系统设置 → 隐私与安全性”中选择“仍要打开”。

更新前请保存工作并退出 Captor。临时签名的构建替换后，旧的屏幕录制、辅助功能、麦克风或摄像头授权可能失效；请通过“设置 → 检查录制环境”处理对应项目，重新授权后按系统提示完全退出并重新打开。重置授权不会删除工程、稿件或素材。
